# プログラミング学習用AR迷路アプリ 要件定義書（最終版）

## 1. プロジェクト概要

### 1.1. 背景と課題
現在、小学校高学年のプログラミング学習ではScratchなどのビジュアルプログラミング言語が広く利用されている。しかし、これらのツールには以下の課題が存在する。
- 画面上での操作が中心であり、児童にとって認知負荷が高い場合がある。
- 一つの画面に向かって一人で作業を完結してしまいがちであり、複数人での協働学習が難しい。

### 1.2. 目的（解決したい課題）
**「物理的なカード（QRコード）とARを組み合わせたプログラミング学習」**
QRコードが印刷された物理カードを読み込むことでプログラムを構築し、AR空間上の3D迷路でキャラクターを動かすアプリケーションを開発する。
これにより、以下の実現を目指す。
- **認知負荷の低減**: 物理的なカード（実体物）を手にとって並べることで、直感的なプログラミング（タンジブル・プログラミング）を可能にする。
- **協働学習の促進**: 複数人の児童が机の上にカードを並べながら、共同でプログラムを考え、画面（またはプロジェクタ等）に向かって学習できる環境を提供する。
- **プログラミング的思考の育成**: ゴールまでの道筋を論理的に組み立てる力を養う。

---

## 2. ターゲットユーザーと利用シーン

### 2.1. メインターゲット
- **小学校高学年の児童**（10歳〜12歳を想定）
- プログラミング学習の初学者〜中級者

### 2.2. 利用シーン
- **小学校の授業・ワークショップ**: 教室内でグループワークとして利用されることを想定。

---

## 3. システム要件

### 3.1. プラットフォーム要件
- **PWA (Progressive Web App)** ベースのWebフロントエンドアプリ
- 学校のChromebook等の端末で、ブラウザからURLにアクセスして利用可能。インストールすることでデスクトップアプリのように振る舞う。
- **完全オフライン対応**: PWAのService Workerのキャッシュ機構を活用し、ネットワーク環境がない教室でもすべての機能（カメラ、3D、迷路編集等）が完全に動作する。バックエンドサーバーは不要とする。

### 3.2. コア機能要件

#### 3.2.1. QRコード読み取り＆プログラム（フローチャート）構築機能
- 端末のカメラ機能を使用して、キャラクターの行動カード（QRコード）を読み取る。
- 読み取った命令を画面上にフローチャートのようにつなぎ合わせてプログラムを構築する。
- **【現在】** 1枚ずつカメラにかざしてフローチャートを構築していく方式。
- **【将来拡張】** 複数枚のカードが整列された状態（例：黒板に貼られた回答）を一括で読み取り、フローチャート化する機能も視野に入れる。

#### 3.2.2. 疑似AR（カメラ映像オーバーレイ）・3D表示機能
- **疑似AR方式**: ARマーカーや空間認識エンジンは使わず、デバイスのカメラ映像を背景として全画面表示し、その上に背景透過の3D空間レイヤーを重ねる方式を採用する。これにより重い計算処理を省き、低スペックのChromebookでも軽快に動作させる。
- 構築したプログラムを実行すると、キャラクターが3D迷路内をアニメーション付きで移動する。

#### 3.2.3. 迷路エディタ機能
- ユーザー（または教師）が独自の迷路を自作・編集できるグラフィカルな機能。
- スタート地点、ゴール地点、壁、障害物などを配置できる。

#### 3.2.4. 迷路管理（一覧）機能
- 作成した迷路、またはプリセットの迷路を一覧表示し、選択・管理できる機能。データはブラウザのローカル（IndexedDB等）に永続化される。

## 4. UI/UX・デザイン要件

### 4.1. デザインコンセプト
- **「楽しく学べるスケッチ風デザイン」**
    - 堅苦しい無機質な画面ではなく、児童が親しみやすく、ワクワクするような手書き風（スケッチ風）の温かみのあるUIを採用する。
- **直感的な操作性**
    - 小学生でも迷わずに操作できるよう、アイコンを大きくし、文字への依存を減らした構成にする。

---

## 5. 技術スタック

- **フロントエンド・アーキテクチャ**: React + TypeScript + Vite (軽量かつ高速なSPA構成)
- **実行環境・配布形式 (ハイブリッドアプローチ)**:
    - **Chromebook・汎用タブレット向け**: PWA (Progressive Web App) としてWeb経由で提供し、オフラインキャッシュ化。
    - **低スペックWindows PC向け**: PWAと同一のWebコードベースを基に、Tauriを用いてネイティブアプリとして軽量にパッケージ。
- **3D・描画レイヤー**: React Three Fiber (R3F) (最適化を施して低スペック機でも軽量に動作させる)
- **QRコード認識**: jsQR 等の軽量JSライブラリ
- **状態管理**: Zustand 等 (UIと3Dシミュレーションの密接な状態同期用)
- **ローカルDB**: IndexedDBベースのラッパー (Dexie.js 等、迷路データ等の完全オフライン永続化用)
