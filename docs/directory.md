# 概要

このファイルは、ProgPathにおけるFSD（Feature-Sliced Design）に基づいたディレクトリ設計をまとめたものである。

エンティティの選定理由や、各レイヤーのスライス・セグメント構成を記載する。

## エンティティ（entities）の選定

`design.md`のドメイン分析から、以下の **4つのエンティティ** を選定した。

### 選定したエンティティ

| エンティティ | 説明                                   | 選定理由                                                                                                                                 |
| ------------ | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **maze**     | 迷路のデータ構造・型定義・表示         | アプリの中核。全画面（ホーム・編集・プレイ）で迷路データを利用し、タイル種別・階層・サイズ等の型定義やバリデーションロジックが集約される |
| **robot**    | ロボットの状態・位置・向き             | プレイ画面でシミュレーションの主体となる。位置(x, y, floor)・向き・アイテム取得状態など独自のデータ構造を持つ                            |
| **command**  | コマンド（プログラム命令）のデータ構造 | QRコードから構築されるプログラム命令（forward, right, left, hole, loop）の型定義と表示を担う。ロボットの行動を定義する独立したドメイン   |
| **folder**   | フォルダのデータ構造・表示             | ホーム画面の迷路整理に使われる。作成・削除・名前変更・開閉状態・迷路の所属管理など独立したCRUD操作を持つ                                 |
