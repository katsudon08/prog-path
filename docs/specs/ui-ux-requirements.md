# UI/UX要件 (UI/UX Requirements)

本ドキュメントでは、ユーザーが操作する画面構成、ウィジェットの振る舞い、および操作体験（UX）に関する要件を定義します。

## 1. 画面構成と遷移 (Screen Transitions)
- **モバイルファースト設計**: 全画面はスマートフォンやタブレットでの閲覧・操作を前提としたレスポンシブデザインとする。また、学校用パソコンでの閲覧・操作も考慮する。
- Tailwind CSS を使用し、一貫したデザインシステム（色使い、余白感、タイポグラフィ）に基づいた見た目を提供する。
- 小学生が親しみやすいようなスケッチ風のデザインを基調とする。

### 主要な画面（Pages）
1. **ホーム画面 (Home)**: 「あそぶ（Play）」と「つくる（Create Maze）」の入り口となるトップページ。最近遊んだ迷路の履歴も表示する。
2. **プレイ画面 (Play)**: 実際のゲーム画面。QRコードをスキャンしてコマンドを取り込み、ロボットを迷路上で動かすメイン画面。
3. **迷路エディタ画面 (Maze Editor)**: 児童がオリジナルの迷路を作成し、シェア用のQRコードを発行したり、読み込むことができる画面。

## 2. 主要ウィジェットの要件
### 2.1. カメラスキャナーウィジェット
- **UI**: 画面の中央に大きなスキャンエリア（カメラプレビュー）を配置する。
- **UX**: QRコードを検出した瞬間に視覚的なフィードバック（枠の色が変わる、緑色のチェックマークが出るなど）と、可能であれば弱めの触覚フィードバック（Vibration API）を提供する。

### 2.2. シミュレーションボードウィジェット
- **UI**: カメラプレビュー領域にオーバーレイする形で、React Three Fiberによる3Dキャンバスを配置する。
- **コントロール**: 下部に「再生(Play)」「リセット(Reset)」のコントロールパネルを固定表示する。

### 2.3. コマンドスタックリスト
- **UI**: 読み取られたコマンドのリストを、カードまたはアイコンの列として縦スクロール可能なエリアに表示する。
- **状態表示**: 現在実行中のコマンドがハイライトされ、どこまで処理が進んでいるかが一目でわかるようにする。
- **階層表現と操作 (Nested UI)**: 
  - `loop` や `if` のブロックは「開始」「終了」の枠として描画され、その「内側」をタップ（選択表示）した状態でQRスキャンを続けることで、その中にコマンドが追記される（ネスト構築）。
  - `loop` ブロックには、回数を変更可能な**数字入力欄**（1〜10のバリデーション付き）が備わっている。
- **条件モーダル (`if`用)**:
  - `if` コマンドのQR（1回目）を読み込んだ直後、画面中央に**条件設定モーダル**がポップアップ表示され、「目の前のマスが〜のとき」という条件（壁、カギ等）をグラフィカルに選択・決定できる。

### 2.4. 迷路エディタ (Maze Editor Widget)
- **UI**: グリッド状（例: 8x8や10x10）のタップ可能なマップを表示する。
- **UX**: ユーザーがパレットから「壁」「スタート」「ゴール」「通路」を選択し、グリッドのマスをタップまたはドラッグしてペイント感覚で配置できる。
- **QR発行**: 作成完了ボタンを押すと、即座にその迷路データをBase64エンコードし、QRコードとして画面上に大きく表示する。

## 3. エラーとフィードバック
- カメラ権限拒否時や、不正なQRコードを読み取った場合は、トースト通知（Snackbar）を用いてユーザーにエラー原因と対処方法を分かりやすく提示する。
- シミュレーション終了時（成功、または壁衝突などによるエラー停止時）は、**カメラ映像やキャンバスの上に大きくオーバーレイする形**で結果（クリア、失敗）のフィードバックを表示する。

## 4. 3Dモデルとアセット (Assets)
- **3Dロボット**: 事前作成済みのGLTF (`.glb`等) モデルファイルを使用し、アニメーション（歩行・旋回等）はファイル内にベイクされたものを利用せず、軽量化と柔軟性のため **React Three Fiber 側でプログラム制御（キャッシュ活用など）** により作成・表現する。
- **マップ要素（床、壁など）**: 外部モデル（GLTF）は使わず、すべて React Three Fiber (Three.js) のプリミティブなGeometryとマテリアルプログラミングによって軽量に動的生成する。
