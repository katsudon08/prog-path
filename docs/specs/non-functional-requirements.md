# 非機能要件 (Non-Functional Requirements)

本ドキュメントでは、システムのパフォーマンス、制約、品質属性に関する要件を定義します。

## 1. パフォーマンス要件
- **3Dシミュレーション (60 FPS)**:
  React Three Fiber上のロボットアニメーションにおいて、一般的なミドルスペック、低スペックのスマートフォンやタブレット、学校用パソコンで常時60FPSに近い描画を維持すること。
  そのため、大量の再描画を引き起こすReact Stateの更新は避け、Three.jsネイティブなアニメーション更新（`useFrame`でのミューテーションなど）を活用する。
- **初期ロード時間**:
  PWAのService Workerキャッシュ活用を前提とし、2回目以降のアクセスにおけるTTI (Time to Interactive) を1.5秒以内とする。

## 2. 対象デバイス・ブラウザ
教育現場やユーザーの持ち込みデバイス（BYOD）を考慮し、幅広く動作することを要件とします。
- **ブラウザ**: Chrome, Safari, Edge, Firefox の各最新2バージョン。
- **OS**: iOS 15以上, Android 10以上, Windows 10以上。
- **ハードウェア**: 背面カメラ（またはインカメラ）の利用が必須。

## 3. インフラ・デプロイ要件
- 静的ファイル（HTML, JS, CSS, アセット）のみで完結するフロントエンド専用（SPA/PWA）アプリケーションとして構成するため、Vercelのような静的ホスティング基盤へのデプロイを前提とする。

## 4. 可用性と耐障害性
- オフライン動作が最重視されるため、必要な静的アセットや3Dモデルファイルは初期ロード時またはインストール時に漏れなくキャッシュに積まれること。
- データ破損（IndexedDBのクラッシュや容量オーバー）が発生した場合でも、アプリケーション自体が起動不能になるのを防ぎ、適切に初期化（データクリア）して復旧する仕組みを備えること。
