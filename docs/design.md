# 概要

このファイルは、ProgPathの実装すべき機能（ドメイン）をページごとにまとめたものである。

## このアプリの概要・背景

本プロジェクトは、小学生のプログラミング教育において児童同士の対話を促進し、教室全体で1つの目的に向かって協調的に学ぶことを支援するために作成する**Web/デスクトップアプリケーション**である。

具体的には、カメラにより**QRコード**を読み込むことで**プログラムのフローチャート**を構築し、3D迷路上のロボットをゴールに導くことでプログラミング的思考を養うことを目的としている。
