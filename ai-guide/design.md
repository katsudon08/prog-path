## 機能

> ドメインにおける小さな機能単位

### 共通UI

| 機能 | 説明 |
|------|------|
| ナビゲーションバー | アプリ名表示、ホーム画面へ遷移するアイコンボタン、現在ページ名表示、ダウンロード画面へ遷移するアイコンボタン |

### ホーム画面

| 機能 | 説明 |
|------|------|
| 迷路一覧表示 | カテゴリごとにグループ化された迷路リストを表示 <br/> 迷路の小プレビューと迷路名を表示 |
| 迷路選択・プレビュー | 迷路を選択して2Dプレビューを表示し、二層以上の場合はレイヤーを切り替えて迷路を表示できる <br/> 迷路の名前、階層、サイズを表示 |
| 迷路実行/作成/編集/削除 | 迷路の実行、作成、編集画面へ遷移、迷路の削除機能 |
| QRコード共有 | 迷路データをQRコードとして表示 |
| QRコードインポート | カメラでQRをスキャンして迷路を読み込みし、迷路リストに追加 |
| フォルダ管理 | カテゴリの作成/削除/リネーム（ダブルクリックでリネームモード） |
| フォルダの折りたたみ/展開 | カテゴリをクリックして迷路リストを折りたたみ/展開、フォルダ内迷路数を表示 |
| 空状態表示 | 迷路が選択されていない時の案内UI |
| ドラッグ&ドロップ | 迷路をフォルダ間で移動 |

### 迷路作成・編集画面

| 機能 | 説明 |
|------|------|
| ホーム画面への遷移 | 迷路作成・編集画面からホーム画面へ遷移 |
| グリッド編集 | タイルをクリックして迷路を構築 |
| タイルパレット | 配置するタイルを選択 |
| サイズ変更 | 迷路サイズを5×5～10×10で変更 |
| 迷路名変更 | 迷路名を変更 |
| 階層管理 | 複数階層の作成・削除・切り替え（1から5層まで） |
| 保存 | 迷路データをlocalStorageに保存 |

### AR実行画面

| 機能 | 説明 |
|------|------|
| 迷路名表示 | 迷路名を表示 |
| 3D迷路表示 | 迷路とロボットを3Dで表示 |
| カメラ映像表示 | カメラ映像を表示 |
| ロボットの移動回数を表示 | ロボットの移動回数を表示 |
| ミニマップ表示 | 俯瞰視点のミニマップ |
| QRコマンド読み取り | カメラでQRをスキャンしてコマンド追加（コマンド読み取り時にコマンド名を表示） |
| コマンドスタック | コマンド一覧の表示・削除 |
| ループ構築 | ループコマンドの構築（回数入力） |
| ホーム画面へ遷移 | AR実行画面からホーム画面へ遷移 |
| 実行/リセット | コマンドを順次実行してロボットを動かす/リセットボタンでロボットの位置をスタートタイルにリセット |
| 成功/失敗表示 | ゴール到達・失敗時のメッセージ |

### ダウンロード画面

| 機能 | 説明 |
|------|------|
| ホーム画面への遷移 | ダウンロード画面からホーム画面へ遷移 |
| リリース情報取得 | GitHub Releasesから最新バージョン取得 |
| ダウンロード | Windows版インストーラーをダウンロード |
| Electron検出 | デスクトップアプリ内からのアクセス検出 |
