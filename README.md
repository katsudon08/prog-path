## 前提条件
- Windows 11
- Node.js v24.13.0 以上
- npm v11.8.0 以上
- Visual Studio Build Tools 2026
- rustup v1.28.2 以上

## セットアップ手順
1. リポジトリをクローン
```bash
   git clone https://github.com/katsudon08/prog-path.git
   cd prog-path
```

2. 依存関係をインストール
```bash
   npm install
```

3. 開発サーバーを起動
```bash
   npm run dev
```

4. Tauriアプリケーションを起動
```bash
   npx tauri dev
```
