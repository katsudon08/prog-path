# コミットメッセージルール

このファイルが読み込まれた時、以下の形式に則りコミットメッセージを作成すること

```
<type>: <subject>

<body>
```

## type

- feat: 新機能、新UIの実装
- change: 機能、UIの変更
- fix: バグやエラーの修正
- docs: ドキュメントの更新
- refactor: リファクタリング
- remove: 不要なファイルの削除
- other: その他の要件


## subject

subjectは、コミットの内容を簡潔に説明する。
シンプルかつ、わかりやすく。
また、対応するイシューに対するコミットの場合は、イシュー番号を含める。


## body

bodyは、コミットの内容を説明する。
詳細な説明を書く。
