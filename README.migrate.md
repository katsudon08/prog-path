移行作業を行うにあたり、READMEに記述されている情報は全てdeprecatedになるため必ずこちらを参照することを心がけてください。

## 環境スタックの移行

現行では、主に`npm` / `next.js` / `Electron`を使用しているが、これを段階的に以下の技術選定へと移行して行きたい。

| 領域 | 名称 | 選定理由 |
| --- | --- | --- |
| ビルドツール | Vite | 設定がシンプルで、爆速のサーバ起動と更新が魅力。かつ、ビルドも早い |
| WEBフレームワーク (厳密にはライブラリ) | React | Next.jsを採用するにはあまりにもオーバースペックすぎるため |
| パッケージマネージャー | pnpm |　ディスク容量の節約と、インストール速度の向上。また、依存関係の厳格化も図ることが可能 |
| デスクトップ | Tauri | 軽量かつ高速。今回のサービスの要件を最も満たしていて、denoに比べて枯れているため採用 |

ただ、移行を行うにあたりこのサービス全体を作り変える作業も同時に行っていくため、順番としては`サービスの作り直し -> 技術スタックの移行`の順に行っていく。
