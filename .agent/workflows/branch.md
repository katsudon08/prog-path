---
description: Issue番号に基づき、branchを切る
---

私に作成するbranchのIssue番号をまず質問してください。

質問して回答が得られた場合、下記のフォーマットに従って新しいbranchを作成し、そのbranchにcheckoutしてください。

以下、フォーマットです。

```
<type>/<Issue>-<branch>
```

type: conventional commitのタイプです
Issue: 私が回答したIssue番号です
branch: `issue.md`作成したIssueのタイトルを2から3単語に圧縮して`-`でつなぐことで、出力してください
